# SAPUDOM Structure Analysis V1.28.4 Fix

This release is a focused 3D visualization/UI correction based on V1.28.3.

Main fixes: global-axis Fx/Fy/Fz arrows, X/Y/Z viewport indicator, independently scrollable 3D analysis result tables, and a fullscreen 3D model view.

The 2D calculation engine and 3D numerical solver are preserved from the previous tested release.
