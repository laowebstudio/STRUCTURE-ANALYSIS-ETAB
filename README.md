# SAPUDOM Structure Analysis V1.28

Integrated 3D Workspace + 3D Frame Analysis Engine Phase 2.

- 3D now opens inside the same central workspace style as 2D, not as the primary modal workflow.
- The existing **3D Model Data** button still opens the proven V1.27.1 geometry/support/load editor.
- 6 DOF per node, 12x12 3D space-frame stiffness, local/global transformation, global K assembly, nodal load solution, reactions and member end forces.
- Model / Deformed / N / V2 / V3 / T / M2 / M3 selectors are available; force diagrams themselves are reserved for V1.29, while V1.28 shows numerical ranges.
- Verified 2D analysis code is preserved.
