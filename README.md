# SAPUDOM Structure Analysis V1.21 — Steel Design Phase 1

Built from V1.20.1 Fix stable baseline.

## Added
- AISC 360-22 / LRFD Steel Design Phase 1
- Axial gross-section tension yielding capacity
- Compression flexural-buckling capacity using KL/r and Fcr
- Axial demand/capacity ratio and PASS/FAIL
- Flexure yield-moment screening ratio
- Governing load combination and KL/r in Design Center
- Run Steel Design and export CSV

## Scope limitation
This phase is intentionally limited. It does not yet implement net-section rupture, local buckling, lateral-torsional buckling, shear strength, or full beam-column interaction. Final engineering review is still required.
