SAPUDOM Structure Analysis V1.39
Load Combinations from Load Cases

GOAL
Move the combination layer to an ETABS-style workflow:
Load Pattern -> Load Case -> Load Combination -> Results

NEW
- Σ Load Combos now references Load Cases instead of Load Patterns.
- Linear Add combination type.
- Default combinations:
  1.4DEAD
  1.2DEAD + 1.6LIVE
  1.2DEAD + 1.0LIVE + 1.0WIND-X
  1.2DEAD + 1.0LIVE + 1.0WIND-Y
- Each term selects a Load Case and Scale Factor.
- Analyze Combo re-solves each referenced Load Case from the current model.
- Combination results include:
  Displacement
  Reactions
  Member End Forces
  Story Response
  Story Forces
  Global Equilibrium
- Results switch immediately to the newly analyzed combination.
- Combination data remains inside model3d for JSON persistence.

MIGRATION
Old V1.36 pattern-based combinations are automatically replaced by Load Case-based
V1.39 defaults so the program no longer bypasses the Load Case engine.

PROTECTED
- V1.38.1 Load Case Result Switching.
- DEAD/LIVE multi-pattern Load Cases.
- Scale Factors.
- Save/Reload JSON workflow.
- Rigid Diaphragm.
- 3D rotate/zoom.
- Pattern solver and Load Assignment.
