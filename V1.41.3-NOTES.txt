SAPUDOM V1.41.3 — RC Beam Detailing Verification

NEW
- Bar fit check inside stirrups.
- Minimum clear spacing check: max(25 mm, db, 4/3 aggregate size).
- User input for nominal aggregate size (default 20 mm).
- Minimum cover verification input (default 40 mm).
- Bars-per-layer and required layer count.
- Multi-layer layouts are REVIEW, not PASS, because current flexural capacity assumes one tensile layer at effective depth d.

- Overall Beam PASS now requires Flexure PASS + Shear PASS + Detailing PASS.
