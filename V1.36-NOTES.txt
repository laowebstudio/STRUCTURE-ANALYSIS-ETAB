SAPUDOM Structure Analysis V1.36 — 3D Load Combinations

NEW
- 3D Load Combinations manager.
- Default linear combinations:
  1.4DL
  1.2DL + 1.6LL
  1.2DL + 1.0LL + 1.0WX
  1.2DL + 1.0LL + 1.0WY
- User can add/delete combinations and terms.
- Pattern/Combination analysis mode in 3D Workspace.
- Linear superposition of solved pattern results:
  displacement vector, global load vector, reactions and member end forces.
- Story Response and Story Forces rebuilt for combination results.
- Existing V1.35.1 Rigid Diaphragm behavior retained.

IMPORTANT
V1.36 is a Linear Add combination layer. It does not yet implement nonlinear combinations,
response spectrum, modal combination, P-Delta, envelope, or code-specific automatic generators.
